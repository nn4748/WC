# نادي الإرشاد الأكاديمي — الموقع

موقع ثابت من صفحة واحدة (`index.html`)، جاهز للنشر على Netlify.

## الربط مع Netlify
1. ادخل [app.netlify.com](https://app.netlify.com) ← **Add new site** ← **Import an existing project**.
2. اختر **GitHub** ثم المستودع `nn4748/WC`.
3. الفرع: `main` — أمر البناء: اتركه فاضي — مجلد النشر: `.` (الإعدادات موجودة مسبقاً في `netlify.toml`).
4. اضغط **Deploy**. أي تعديل يُرفع على `main` بينشر تلقائياً.
